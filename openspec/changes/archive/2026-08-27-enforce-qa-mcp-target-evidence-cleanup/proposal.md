## Why

After published OSS-04E-R1 admission, project tools must still be unable to retarget operations,
evidence or cleanup. This final bounded payload closes schemas and cleanup
authority and certifies the complete behavior against native Linux and Windows
contours.

## What Changes

- Hide physical target, endpoint, credential, rebind and retention controls from
  project-bound MCP schemas and inject provider-owned values.
- Route representative read/display operations through the current
  target/session executor and emit bounded artifact provenance.
- Restrict local and Windows cleanup to exact lifecycle-owned resources; detach
  non-owned sessions and refuse stale or foreign handles.
- Reconcile or rerun source-bound Linux/Windows lifecycle/read/display/cleanup
  evidence, including negative no-alternate-target proof.

## Capabilities

### New Capabilities
- `qa-mcp-target-bound-evidence-cleanup`: Project-bound tool schemas, evidence
  routing and exact-owned cleanup with native runtime certification.

### Modified Capabilities
- None.

## Impact

Python MCP composition, lifecycle cleanup, display routing, tests, docs and
ignored runtime evidence change. Fresh exact-final-source Linux and authorized
Windows-native live 1C verification is mandatory; the exhausted OSS-04E stash
and older oversized evidence are lineage only. No new protocol mapping,
Vanessa MCP or EDT/meta snapshot is introduced.
