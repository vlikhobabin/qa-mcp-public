## Why

S7 final certification is blocked because published S4 cannot observe a main
window for the tracked form-bearing EPF on the authorized Windows contour.
Synthetic hidden lifecycle and real S3 pass, while the same EPF opens visibly,
so another S7 integration patch would violate predecessor byte identity without
first locating the causal boundary.

## What Changes

- Add test-only or ignored-runtime diagnostics that compare exact S3 and S4
  argv, environment, process/job/desktop identity, exit and top-level-window
  timelines without recording raw UI or credentials.
- Reproduce the initial transient desktop-enumeration failure and stable
  `main_not_ready` state twice on the exact authorized target.
- Publish an evidence-backed decision identifying a fixture/environment/runbook
  correction, a bounded replacement-card scope, or an exact `NOT-VERIFIABLE`
  resume condition.
- Preserve published S1-R1 through S6 and blocked S7 production bytes; add no
  caller, public capability, cleanup authority or protocol claim.
