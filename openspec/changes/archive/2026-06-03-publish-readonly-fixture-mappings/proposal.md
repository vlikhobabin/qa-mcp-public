## Why

Reviewed fixture classifications need to be discoverable from the protocol
research docs, but only evidence-backed rows should change accepted mapping
documentation. This change publishes compact fixture results while preserving
unresolved families.

## What Changes

- Update the evidence index and corpus/mapping docs to link the reviewed
  fixture source, corpus, probe, comparison and accepted-mapping evidence.
- Promote only rows classified as accepted by the previous change.
- Keep unresolved families visible with status and next owner.
- Avoid rewriting raw captures, historical corpus rows or previous accepted
  mapping evidence.

## Capabilities

### New Capabilities

- none

### Modified Capabilities

- `qa-mcp-protocol-lab`: require fixture mapping publication to be gated by
  reviewed classification evidence and to preserve unresolved family status.

## Impact

- Touches protocol research docs and compact evidence index files.
- May update accepted-mapping docs or protocol package notes only for reviewed
  accepted fixture rows.
- Requires no live 1C runtime unless publication discovers a missing evidence
  link that must be regenerated by an earlier change.
