# Происхождение общего runtime

Общий native runtime распространяется на условиях MIT из `LICENSE`.
Исходная история ChangeRail: commit `051e99be6c696ae07e8eaa596fdb714cc00378e2`.
Кандидат 2.0.0-rc.3 объединяет независимо развивавшиеся локальные реализации native
lifecycle и проверяемых evidence. Конкретные байты кандидата определяются
манифестом дистрибутива, а не идентификатором старого релиза.

Выпуск публикуется как предварительный релиз с тегом `v2.0.0-rc.3`. Исторический
`upstream_commit` не обозначает release commit. Точные source commit, source tree
и SHA-256 архива записываются отдельно в `release-provenance.json` рядом с архивом.
Runtime не зависит от checkout, из которого был собран архив. Все установленные
копии должны совпадать с общим манифестом; проектные настройки остаются отдельно.
