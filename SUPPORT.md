# Support

qa-mcp is pre-release community software.

- Use repository Issues for reproducible bugs and feature requests.
- Use repository Discussions for usage and design questions when enabled.
- Use private vulnerability reporting for security issues; see
  [SECURITY.md](SECURITY.md).

Include the qa-mcp commit/version, Python version, operating system, 1C platform
family when relevant, selected tool profile and sanitized error output. Replace
usernames, infobase names, paths, private addresses and business data with
placeholders. Never post tokens, passwords, full captures, infobases or
customer data.

Live 1C behavior depends on a licensed platform installation and a test target;
the project cannot provide 1C licenses or support proprietary platform files.
No service-level response time is promised.
